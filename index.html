Retail compliance platform for a national supermarket chain

A portal where franchise holders of a national Dutch supermarket chain track their compliance measurements, order additional audits, and book on-site training workshops.

  • Role-based access for four user types, with enterprise SSO (OAuth2/PKCE) and SCIM user provisioning against the client's identity platform.
  • Excel-driven bulk imports (≈735 rows × 46 columns) with preview, per-cell validation and server-side re-validation; cell color carries meaning and is parsed as data.
  • Automated compliance scoring with threshold rules, alert emails on failing scores, and a self-service workshop scheduler that auto-assigns trainers by region, weekly pattern and workload.
  • A second measurement stream via public token-based forms and a webhook integration (HMAC-verified, idempotent) with evidence-file handling, stored encrypted.
  • Security hardening: middleware auth with header-spoofing protection, per-action role checks, ownership checks on mutations, rate limiting on public endpoints.
TypeScript · Next.js · PostgreSQL · Prisma · Better Auth · Docker · Caddy · Resend · SheetJS · vitest
Production · field-research operations

Field-research data platform

An operational system for planning, executing and processing on-site research visits: order intake, day-team planning, a separate portal for field workers, and an immutable measurement chain from visit to reported result.

  • Monorepo with a typed API and a web app; measurements are append-only by design so results stay auditable.
  • Order-code chain connecting client orders to visits and results, with staging and production environments on the same host.
  • Operated end-to-end: deployments, database backups with restore runbooks, secrets management, monitoring.
TypeScript · Hono · Next.js · Drizzle ORM · PostgreSQL · pnpm monorepo · Docker

How I work

I build with AI coding agents as the executing developers and myself as architect, reviewer and operator. That combination is why a one-person team can deliver and run systems of this size: rigorous specification, structured review of everything the agents produce, and conventional engineering discipline — tests, migrations, runbooks, backups — around it.

Before building software I spent 25 years designing national behavior-change programs in Dutch public health, which is where the evaluation habits come from: define the criteria first, then measure against them.
